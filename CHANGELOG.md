# What's new in Blog Builder

## 2.0.1: Releases Straight from GitHub
_2026-11-04_

- Signed Releases: New versions now go to npm straight from GitHub, with a signature you can check on npm. Nothing changes in your blog.

## 2.0.0: Free and Open Source
_2026-11-03_

- Free and Open Source: Blog Builder is now free for everyone, with the code on GitHub under the MIT licence. There's no licence key or trial, and every theme is included.
- Pick Your Theme in the Admin: Choose any of the 16 themes on the Blog Builder page in your blog's admin, and switch whenever you like.
- Install from npm: The installer is now a command you run in your terminal, npx @mrpwob/blog-builder setup. It installs into your own Cloudflare account.
- Updates from GitHub: The Blog Builder page in your admin tells you when a new release is out.

## 1.3.1: Home pages for every theme
_2026-10-22_

- Theme home pages: The five basic themes now have their own home page layouts.

## 1.3: Themes and plugins
_2026-10-22_

- Sixteen themes: Six themes come included, plus ten more that were the premium pack. All sixteen are free.
- Plugins: Plugins are built in, so you can add features without touching the code.

## 1.1: Moving from WordPress
_2026-10-21_

- Old links keep working: Moving from WordPress? Your old post addresses go straight to the same posts on your new blog.
- Embeds load when clicked: Embedded videos and posts load only when a reader clicks them, so pages stay fast and private.
